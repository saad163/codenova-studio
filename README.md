## 🚀 Local Setup & Installation

Get the development environment running locally in minutes:

### Prerequisites
*   Node.js (v18 or higher recommended)
*   npm (v9 or higher)

### 1. Clone the repository
```bash
git clone https://github.com/saad163/codenova-studio.git
cd codenova-studio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 4. Compile production build
To test the production asset optimization and verify TypeScript types:
```bash
npm run build
```
The compiled, highly-optimized production chunks will build directly into the `/dist` directory.
